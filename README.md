# Лабораторные работы по Java 1–8

Восемь модулей с исходниками, тестами, данными и отчётами. Ответы на 77 контрольных вопросов находятся в `reports/Ответы на вопросы.docx`; текстовая копия — рядом в Markdown.

## Требования и сборка

- JDK 17 или 21; проверено на Amazon Corretto 21.
- Maven 3.9 и доступ к Maven Central при первой сборке.
- Для №6 и №8 — PostgreSQL; для веб-части №8 — Tomcat **10.1** (не Tomcat 9).
- JavaFX Maven загрузит сам. Docker Compose — необязательный способ запуска PostgreSQL и Tomcat.

Откройте терминал в папке `JavaLabs`, где находится общий `pom.xml`:

```powershell
mvn clean install
```

Команда собирает восемь модулей и запускает 12 JUnit-тестов. №2–4 используют общие классы №1. Все команды ниже выполняются из того же корня. Кавычки вокруг `-D...` удобны для PowerShell. Названия классов английские: Car — Автомобиль, Motorcycle — Мотоцикл, Transport — Транспортное средство.

## Работа 1

```powershell
mvn -pl lab01 exec:java "-Dexec.mainClass=labs.TransportUtils"
```

Проверяются обе реализации, выводятся модели, цены, среднее и сообщения о трёх ошибках. Конструктор с размером N создаёт Model1…ModelN с ценой 0. Цены должны быть конечными и неотрицательными; имена — непустыми, однострочными, уникальными. Среднее пустого набора не определено.

## Работа 2

```powershell
mvn -pl lab02 exec:java "-Dexec.mainClass=labs.IODemo"
mvn -pl lab02 exec:java "-Dexec.mainClass=labs.IODemo" "-Dexec.args=--stdin"
```

Первый запуск создаёт transport.bin, transport.txt и transport.ser в текущей рабочей папке; сверяет сохранённые значения и печатает текст в System.out. Для второго введите по строке: `Toyota`, `1`, `Corolla`, `100`. После последней строки программа выводит тот же объект; завершение ввода не требуется. Имена с пробелами поддержаны. Файловая кодировка UTF-8; пользовательский формат восстанавливает Car, стандартная сериализация сохраняет фактический тип. Поле lastModified намеренно transient.

## Работа 3

```powershell
mvn -pl lab03 exec:java "-Dexec.mainClass=labs.ThreadDemo" "-Dexec.args=lab03/data 1"
mvn -pl lab03 exec:java "-Dexec.mainClass=labs.ThreadDemo" "-Dexec.args=lab03/data 5"
```

Параметр 1–5 задаёт ёмкость очереди. Повторите запуск: независимые выводы и порядок марок могут различаться; согласованное чередование остаётся одинаковым. В конце показан отдельный опыт заполнения через add без потребителя. put ждёт свободного места, add выбрасывает исключение при переполнении. В исходнике поток-производитель использует put, потребитель — take; ожидание потребителя ограничено тайм-аутом через Future.

## Работа 4

В первом терминале запустите один из серверов:

```powershell
mvn -pl lab04 exec:java "-Dexec.mainClass=labs.SequentialServer"
# либо
mvn -pl lab04 exec:java "-Dexec.mainClass=labs.ParallelServer"
```

Во втором:

```powershell
mvn -pl lab04 exec:java "-Dexec.mainClass=labs.Client"
```

Ожидается `Average = 300.0`. Сервер слушает localhost:5050, остановка — Ctrl+C. Другой порт передаётся серверу как `-Dexec.args=5051`, клиенту как `-Dexec.args=localhost 5051`. Не запускайте оба сервера на одном порту. Параллельный сервер можно проверить несколькими одновременными клиентами. Среднее считается по всем моделям, а не по средним транспортных средств.

## Работа 5

```powershell
mvn -pl lab05 javafx:run
```

Кнопки: +, −, *, /, sqrt, ^, C, =, ±. Клавиатура: цифры, операторы + - * / ^, точка/запятая, Enter, Backspace, Escape; `c` также сбрасывает. sqrt и смена знака доступны кнопками. Проверка: `3 + 5 *` показывает 8, затем `2 -` — 16, `4 =` — 12. `2,,,,,56` отображается как `2,56`. Проверьте `1 / 0 =`, отрицательное число с sqrt и букву: появляется сообщение ошибки. Тесты покрывают вычислительную логику; интерактивная визуальная проверка всех клавиш не автоматизирована.

## Работа 6

Создайте отдельную учебную БД `music_store` и пользователя `lab` с паролем `lab`, либо запустите:

```powershell
docker compose up -d db
```

По умолчанию используется `jdbc:postgresql://localhost:5432/music_store`. Для своей БД задайте:

```powershell
$env:DB_URL='jdbc:postgresql://localhost:5432/music_store'
$env:DB_USER='lab'
$env:DB_PASSWORD='lab'
mvn -pl lab06 exec:java "-Dexec.mainClass=labs.JdbcDemo" "-Dexec.args=--init"
```

`--init` нужен один раз на пустой схеме: создаёт таблицы и данные из lab06/sql. Для повторной демонстрации опустите его. Скрипты также можно выполнить через psql по порядку 01_schema.sql, 02_seed.sql, 03_queries.sql. CREATE DATABASE выполняется отдельно, вне транзакции скрипта.

Запрос учитывает **альбомы с минимум пятью композициями**, как уточнено в задании. Длительность хранится в секундах. Четыре альбома по шесть треков проходят фильтр, пятый с тремя — нет. При совпадении минимальной длительности возвращаются все самые короткие треки. CRUD создаёт временного исполнителя, изменяет его и удаляет в одной транзакции.

## Работа 7

```powershell
mvn -pl lab07 exec:java "-Dexec.mainClass=labs.AverageCorrector" "-Dexec.args=lab07/data/student.xml lab07/data/corrected.xml"
```

Среднее 3.5 заменяется на 4. Если average отсутствует — добавляется; если предметов нет — удаляется. Неверная оценка, порядок элементов или атрибут приводят к ошибке валидации. Дробное среднее округляется до 10 знаков. Программа принимает только поставляемую внешнюю student.dtd, запрещает произвольные внешние источники.

Откройте `lab07/web/index.html` в браузере. Сервер не требуется: GET-параметры передаются на result.html. HTML, CSS и JavaScript находятся в разных файлах. Фотография Земли NASA включена локально и указана как пример — замените earth.jpg своей любимой фотографией, если требуется персональное изображение. Источник: https://images.nasa.gov/details/as17-148-22727 (Apollo 17, public domain).

## Работа 8

Используется существующая БД из №6. Следующая команда **удаляет и создаёт заново три учебные таблицы и их последовательности**, как требует №8; БД сохраняется. Запускайте её только для учебного music_store:

```powershell
mvn -pl lab08 exec:java "-Dexec.mainClass=labs.HibernateDemo" "-Dexec.args=--reset-lab-tables"
```

Повторная демонстрация без сброса:

```powershell
mvn -pl lab08 exec:java "-Dexec.mainClass=labs.HibernateDemo"
```

Для веб-интерфейса скопируйте `lab08/target/music-store.war` (или готовый `dist/music-store.war`) в webapps Tomcat 10.1 и запустите Tomcat с теми же переменными DB_URL/DB_USER/DB_PASSWORD. Адрес: http://localhost:8080/music-store/store.

При использовании Compose после сборки и инициализации Hibernate:

```powershell
docker compose up -d web
```

В веб-интерфейсе есть просмотр, создание, изменение и удаление для всех трёх таблиц. Чтобы удалить исполнителя или альбом, сначала удалите дочерние записи. Два отчёта соединяют по две/три таблицы: кратчайшие композиции подходящих альбомов и статистика исполнителей. Начните вводить `Au` в имя исполнителя — AJAX предложит Aurora Band; подсказки также работают для названия альбома, жанра и трека. Обычный запуск веб-приложения проверяет схему (`validate`) и не пересоздаёт её.

Учебная конфигурация не содержит учётных записей пользователей приложения; она предназначена для локальной демонстрации. Hibernate использует встроенный пул соединений. Compose публикует порты только на 127.0.0.1.

## Состав архива

- lab01…lab08 — исходники, Maven-конфигурации, тесты и данные.
- reports — восемь отчётов DOCX и ответы на 77 вопросов.
- dist — собранный WAR для Tomcat.
- ПРОВЕРКИ.md — фактически выполненные проверки и ограничения.
- compose.yaml — необязательная инфраструктура для локального запуска.

Версии зависимостей закреплены в pom.xml, выбраны для совместимости этой учебной работы и не обозначаются как последние. Документация: [OpenJFX](https://openjfx.io/openjfx-docs/), [Hibernate 6.6](https://hibernate.org/orm/releases/6.6/), [Tomcat 10.1](https://tomcat.apache.org/tomcat-10.1-doc/).
